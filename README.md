# Hermes Agent — capacidades

Página estática (un solo `index.html`, sin dependencias ni build) que explica qué es
Hermes Agent, qué ha hecho y qué puede hacer.

**Ver:** https://v3rne42.github.io/hermes-capabilities/

- HTML + CSS embebidos, cero JavaScript.
- Tema oscuro, responsive, navegación sticky con anclas.
- Contenido en español.

Editar `index.html` y hacer push a `main`: GitHub Pages sirve el cambio solo.
